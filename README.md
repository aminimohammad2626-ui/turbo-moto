# TURBO MOTO 🏍️

A 3D motorcycle racing game in a single HTML file, built with Three.js.

## Play
Open `index.html` in any modern browser (internet needed for the Three.js CDN).

## Controls
| Key | Action |
|---|---|
| W / ↑ | Accelerate |
| S / ↓ | Brake |
| A / D or ← / → | Steer |
| Shift | Nitro |
| C | Camera mode |
| R | Reset bike |
| M | Mute |
| Esc | Pause |

Touch controls are shown automatically on mobile devices.
